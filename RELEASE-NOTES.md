Исправлена ошибка установки «holds no native mod» в лаунчере Horizon.

Теперь cosmic.hnmod содержит нативный Rust-движок, манифесты лаунчера,
адаптеры ввода, интерфейса, звука и рендеринга, а также оригинальные ресурсы.
Мод закреплён на Horizon e57b1d34bb0dcf6bf081c19fe6d2e7f69b60cdf4.

Добавьте https://github.com/Egor-ship/cosmic-cataclysm через GitHub в лаунчере,
включите мод и выполните нативную сборку. В творческом мире: /cosmic control.
Пульт в руку, R — выбор планеты, правая кнопка — запуск, X — отмена.

Версия экспериментальная. Космическая сцена использует виртуальную камеру шейдера.
Обломки визуальные, разрушения по умолчанию выключены. Запуск в настоящей игре
ещё требует проверки; графический предпросмотр проверен на RTX5070.
